# Day 2: Linux Basics

## Commands I practised
- pwd : shows the folder I am in
- ls : lists files in a folder
- ls -l : lists files with details and permissions
- cd folder : moves into a folder
- cd .. : goes up one folder
- mkdir name : creates a folder
- touch file : creates an empty file
- echo "text" > file : writes text into a file
- cat file : prints what is inside a file
- grep "word" file : searches for a word inside a file
- nano file : opens the text editor

## Nano shortcuts
- CTRL + O then Enter : save
- CTRL + X : exit

## Git routine
- git add . : pick up my changes
- git commit -m "message" : save a snapshot
- git push : upload to GitHub

## What I learned
Linux is used everywhere in cybersecurity, so being
comfortable in the terminal comes first.
